## Art direction

The organising device is an original **signal aperture**: luminous concentric ellipses, dotted fields and intersecting data threads collect toward a single citron decision marker. Charcoal, warm white, citron; large tightly tracked system sans-serif and small monospace metadata. Graphic density diminishes through three states. Fine rules, annotation marks and restrained grain feel like an analytical film title rather than a software dashboard. No stock imagery, borrowed graphics, licensed font binaries, video downloads or new runtime dependencies.

## Storyboard and hierarchy

1. **Noise / opening:** headline, identity and CTA are immediately legible over a bounded full-width procedural scene. Fixture-derived signals drift for 0–3s, align through 3–6s, converge during 6–9s and settle by 12s. The headline gains emphasis but is never hidden. Skip and Pause remain available. The sequence is finite; there is no infinite background animation.
2. **The contradiction:** a compact campaign readout carries engagement and revenue into the question. The signal trace splits into incompatible directions, labelled with real fixture values.
3. **Signal / investigation:** a three-way inquiry selector changes explanatory copy, exact numbers, native controls and the visual model. Duplicate purchase-event tokens separate into 100 unique orders + 20 duplicates; attribution paths reallocate USD 150; cohort flows compare the same before/after counts at selected scope.
4. **Pressure / red team:** all six challenges remain. The response has a corresponding semantic state: interrupted tracking, independent sample boundaries, moved attribution credit, missing labels, observation vs counterfactual, or commercial hurdle. Labels and recommendation text carry the meaning even without animation.
5. **Decision / resolution:** an ivory field replaces the dark field. Problem, selected finding, uncertainty, action and source are explicit. Current-state download stays local and reproducible.
6. **Proof / invitation:** commit-pinned technical evidence, selected work, resume status and contact. Always directly reachable from navigation; no lengthy scroll lock or compulsory intro.

## Motion contract

One global session-only pause control governs native CSS animation and transitions. Intro progression pauses with it and stops when the tab is hidden or the hero leaves view. A late-enabled reduced-motion or Save-Data preference immediately cancels playback. Default SSR/no-JavaScript presentation is a complete, static decision composition. IntersectionObserver adds small finite line/scene reveals when available; content is never hidden pending an observer. Unsupported observers fail open. No scroll hijack, pointer trails, WebGL or continuous canvas rendering. No flashing, large moving copy or parallax.

Data diagrams use existing deterministic calculations. Animation responds to selected inputs, never random numerical values. Animated diagrams are aria-hidden where an adjacent labelled count/table gives the exact meaning. Live announcements are concise and do not read animation frames. Focus is not moved by a visual transition.

## Media plan and failure modes

Produce inline SVG/CSS motion as authored source, not a claimed rendered video. No streaming/video dependency; no decoder, poster download, autoplay sound or extra media request. The SVG's static shapes are their own poster frame. If CSS, motion APIs or JavaScript fail, typography, counts, source links, default PDF and contact remain. An explicit resume-availability note is part of the proof section.

## Responsive and performance strategy

Desktop composition uses the aperture across the right and lower hero, with readable copy in a dark safe area. Mobile reduces the number of signal labels, avoids a sticky viewport trap and uses a compact aperture below the headline. Sticky navigation is small, horizontally scrollable on narrow screens and does not obstruct focused content. Inquiry views stack without horizontal page overflow. All controls target at least 44px; native select/range controls retain keyboard behaviour. Safe-area spacing is reserved for sticky controls.

Reuse Next static export, React and CSS/SVG only. No new production dependencies, external fonts or heavy media. Animate transforms/opacity for narrative motion; limit SVG paths and DOM count. Original source/assets are created in this repository. Measure v1 and v2 with the same Lighthouse version, Chromium, local static server and default mobile simulation; preserve full reports. Investigate LCP/CLS/TBT and payload changes, not only headline scores.
