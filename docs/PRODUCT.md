# THE UNAPPLICATION · R/GA — 001

Independent candidate experience for Yash Hurdale. Exclamation AI remains the separately maintained engineering evidence; this repository owns the recruiter journey. No changes are required in Exclamation AI.

## Product and journey
A 60–90 second primary route: hook (10s) → synthetic campaign contradiction (10s) → choose one investigation (20s) → challenge one assumption (15s) → executive decision (10s) → inspect proof/contact (15s). Timing is a design target, not a measured recruiter study.

Single-page sitemap: 00 Hook; 01 Brief; 02 Investigation; 03 Engine; 04 Red team; 05 Decision; 06 Proof. Direct anchor navigation and an expedited route preserve optional depth. Keyboard-operable native buttons change real content and calculations. A sensitivity slider changes missing-purchase assumptions; attribution rules change revenue allocation; cohort selection changes funnel counts. Challenges revise the recommendation and exported brief. No login, tracking, payments or live AI.

## Visual system
Editorial near-black canvas, warm ivory type, acid-yellow accent; oversized compact typography, ruled rows, a typographic U/ device and number-led information. System sans-serif stack avoids font downloads and extra licences. 8px spacing scale; 1px rules; 640/960/1280px breakpoints. Minimum 44px control targets, visible focus, high contrast, native semantics and reduced-motion support. No autoplay, artificial progress or decorative 3D. CSS handles purposeful transitions; a motion dependency adds no necessary value.

## Architecture
Next.js App Router static export + React + strict TypeScript. CSS tokens replace Tailwind because one editorial page benefits from direct styles and fewer build dependencies. No backend or paid services. Configuration is separated into candidate, target, evidence and scenario content. Pure analytics functions own every computed value. An accessible HTML decision brief downloads with current selected assumptions and can print to one PDF page. A committed default PDF offers a direct download. Tests cover numerical boundaries, scenario branches, evidence integrity, React state, browser journeys, downloads and accessibility.

## Acceptance and risk register
- Evidence over claim: all achievement copy links to commit-pinned artifacts. Upstream receipts are historical documentation, not current reruns or independently authenticated cloud verification.
- Synthetic results are never attributed to R/GA or clients. Historical Google data is a separate source.
- Missing resume: no approved resume was found; omit fabricated download and explicitly disclose the gap.
- Background: existing owner portfolio states business analytics/data science and operations; these are owner-published statements, not independently verified credentials. Avoid degrees/employer assertions in public copy.
- Role listing inaccessible: supplied company/role is the target; exact requirements remain unverified.
- Weak attribution, small samples, missing data and costs must change the decision. No causal or uplift claims.
- Recruiter timing, manual screen-reader testing and owner ability to explain the work require human validation.
- External artifacts may disappear; commit pinning and labelled evidence boundaries reduce drift but do not guarantee availability.
- Public publication requires owner visibility approval. Repository is private at creation; hosted review is private.
